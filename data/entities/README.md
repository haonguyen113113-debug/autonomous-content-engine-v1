# Entity Seed Data

This directory contains versioned, human-readable source manifests for the football Entity Catalog.

The SQLite catalog is runtime state derived from these manifests; it is not the canonical source of entity identity.

Current snapshot: 2026-09-28

Seed scope:

- Premier League 2026/27 clubs
- UEFA Champions League 2026/27 league-phase clubs
- LPBank V.League 1 2026/27 clubs
- Vietnam men's national-team identity

Sources are recorded in manifest metadata and participation relationships. External provider IDs are intentionally not invented; they should be added only when verified.
