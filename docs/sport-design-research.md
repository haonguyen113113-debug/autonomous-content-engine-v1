# Sports-channel template research + card anatomy (Oct 2026)

Research: SVG scorebug roundtable (type carries brand, info only when useful,
motion is functional), School of Motion sports lower-thirds (angular condensed
type, fast in/out), BoxOut/Captivate sports kits (duel splits, winner color,
photo + stat columns), Tifo/FMS analyst grammar (one idea per graphic).

## Set 1 — Match kit, red/black (12 tiles + hero)

1. `goal_card`: backdrop word GOAL ~70% canvas (dark red on red) + foreground
   chant line GOAAAAAAAAAL white condensed + micro ticker borders top/bottom.
2. `player_intro`: full-bleed cutout + red pill lower-third + ghost GO behind.
3. `fixture_card` (NEXT MATCH): centered condensed header, V + 2 shield slots,
   datetime + stadium micro, marquee ticker borders.
4. `duel_table` (STATS black): header + 2 shield dots; rows
   left-value / LABEL / right-value in micro numerals.
5. `quote_card`: red duotone photo + white paper box, quote + name + red seal.
6. `potm_card`: dark photo + giant POTM red + name pill.
7. `discipline_card` (RED CARD): vertical R/D edge letters, card-motif rows,
   name + minute footnote.
8. `fixture_list` (UP NEXT): UP + chevrons NEXT header, white panel, 3 rows of
   shield / date / shield.
9. `thanks_card`: diagonal pinstripes, THANK YOU condensed, red pill, photo.
10. `welcome_card`: X-cross background, WELCOME header, photo, black pill.
11. `score_card`: full-bleed action photo + giant condensed scoreline + shield bug.
12. `stat_leader` (hero): red field, white micro label / giant black numeral
    rows, cutout right, STATS footer.

## Set 2 — Player posters (2 structures x 4 colorways)

- Structure A (side split): photo left with torn edge + color field right;
  firstname small caps, SURNAME brush giant overlapping both zones;
  #number tag; meta column + divider + stats column (giant number + micro label);
  diagonal ticker tape with repeated name.
- Structure B (top photo): photo top with torn bottom edge, field below;
  name block, 3 meta columns, rule, STATS header, 3 giant stat columns.
- Fields: red / navy / orange / yellow. Brush: black or neon green, latin only.

## Set 3 — DEF comparison duel

Header band (title + teams + records), navy vs orange zones, photo flanks,
6 rows of centered small-caps label + giant numerals; **winner numeral lime,
loser white**. This is the winner-highlight rule v9 adopts for all duels.

## Grammar rules extracted (all sets)

- 1 frame = 1 boss (giant numeral / backdrop word / surname). Max 3 type sizes.
- Zones carry meaning by color; values never by color alone (winner also bolds).
- Micro labels small caps; provenance (date/stadium/source) always WHISPER.
- Texture: torn edge, ticker tape, pinstripes, marquee tickers, grain, vignette.
- Reading order: header -> boss -> support -> whisper; left-to-right duel.
